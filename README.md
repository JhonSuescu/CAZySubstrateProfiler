# CAZySubstrateProfiler

**A genomic approach to infer bacterial carbohydrate degradation potential based on CAZyme annotations.**

CAZySubstrateProfiler is an R-based application designed to analyze carbohydrate-active enzyme (CAZyme) annotations and infer the potential carbohydrate degradation capabilities of bacterial genomes.

## Overview

The application aims to provide a systematic and reproducible framework for associating CAZyme families with potential carbohydrate substrates, facilitating the functional characterization of bacterial carbohydrate degradation profiles.

## Features

- CAZyme annotation data processing.
- Substrate-associated CAZyme family profiling.
- Inference of potential carbohydrate degradation capabilities.
- Generation of structured output files and substrate profiles.
